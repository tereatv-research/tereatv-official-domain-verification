# TereaTV Official Domain Verification

This repository is the public, auditable companion to the TereaTV brand-domain consolidation project.

## Official domain roles

- Primary brand destination: <https://tereatv.net/>
- Legacy official domain: <https://tereatv.com/>

The intended migration is a page-to-page permanent redirect from the legacy `.com` URLs to their closest `.net` equivalents. Until the migration is deployed and verified, visitors should use the primary `.net` destination for current brand information and confirm commercial details directly with the provider.

## What this project contains

- A human-readable official-domain verification page.
- Machine-readable domain-role data in `official-domains.json`.
- A migration runbook and redirect templates under `migration/`.
- A crawlable sitemap, robots file, canonical metadata and structured data.

## Editorial and ownership disclosure

This is a brand-owned verification resource, not an independent customer-review page. Its purpose is to reduce domain confusion and document the official migration path. It does not make claims about unrelated domains or operators.
